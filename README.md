# LMT-Code-Generation-Protocol
技術的赤ちゃんのための、コード生成プロトコル

## これは何？

コードを自分で書けない前提で、  
AIに「目的と構造をちゃんと守ってコードを書いてもらう」ための運用ルールです。

「とりあえず動くコード」ではなく、  
・目的が明確で  
・後から人間が追跡できて  
・修正しやすいコード  

を生成するためのプロトコルです。

## 使い方

1. コードを生成してほしいときに、このプロトコルをAIに渡す
2. AIは指定された出力フォーマットに従って回答する
3. 実装後はセルフレビュー観点で確認する
4. 必要に応じてテストと修正を繰り返す

詳細は `CODE_GENERATION_PROTOCOL.md` を見てね。

Before：
「この機能を作って」

After：
LMTコード生成プロトコルを付けて依頼
→ 目的、前提、変更ファイル、テスト、復旧方法まで出力
